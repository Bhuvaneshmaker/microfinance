# Microfinance Loan Management System

This repository contains a starter full-stack web application for a microfinance loan management system.

## Stack
- Frontend: React (JavaScript) with Vite
- Backend: Node.js + Express
- Database: PostgreSQL with Prisma ORM

## Setup
1. Install dependencies for backend and frontend:
   - `cd backend && npm install`
   - `cd ../frontend && npm install`
2. Configure the backend database connection in `backend/.env`.
3. Initialize the database:
   - `cd backend && npx prisma migrate dev --name init`
   - `cd backend && npx prisma db seed`
4. Start the backend and frontend:
   - `cd backend && npm run dev`
   - `cd ../frontend && npm run dev`

## Environment

Backend (`backend/.env`):

```env
DATABASE_URL="postgresql://USER:PASSWORD@HOST:5432/microfinance?sslmode=require"
JWT_SECRET=replace_with_a_secure_random_secret
PORT=4000
NODE_ENV=development
CORS_ORIGIN=http://localhost:5173,https://microfinanceapplive.netlify.app
```

Frontend (`frontend/.env`):

```env
VITE_API_URL=https://microfinance-sooty.vercel.app
```

For local development, use `VITE_API_URL=http://localhost:4000`. The frontend automatically appends `/api` when needed.

## Deployment

### Frontend on Netlify

- Base directory: `frontend`
- Build command: `npm ci && npm run build`
- Publish directory: `dist`
- Environment variable: `VITE_API_URL=https://microfinance-sooty.vercel.app`

The app includes `frontend/public/_redirects` so browser refreshes like `/login` work on Netlify.

### Frontend on Vercel

- Root directory: `frontend`
- Framework preset: `Vite`
- Build command: `npm run build`
- Output directory: `dist`
- Environment variable: `VITE_API_URL=https://microfinance-sooty.vercel.app`

The app includes `frontend/vercel.json` so browser refreshes like `/login` work on Vercel.

### Backend and PostgreSQL on Render

The root `render.yaml` provisions:

- A Node.js web service from `backend`
- A hosted PostgreSQL database
- `DATABASE_URL` wired from the hosted database
- `JWT_SECRET` generated by Render
- `CORS_ORIGIN=https://microfinanceapplive.netlify.app`

Render runs `npm run prisma:migrate:deploy && npm run prisma:seed` before starting the backend, so the hosted database gets the schema and demo users.
